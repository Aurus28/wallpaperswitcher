**Simple KDE Plasma Wallpaper Switcher**

Allows for a Popup to open out of the widget and lets you pick a wallpaper to apply.

**Features:**
- Keyboard navigation (hjkl / arrow keys / enter)
- visual customisation in the settings
- Option to hide the widget (thus you see nothing unless you press the shortcut, in which case the popup opens)
- Option to also change the lockscreen wallpaper

**Installation:**

Option 1:
Install it from the Widget-Store inside plasma: `right click the desktop` -> `Enter Edit Mode` -> `Add or Manage Widgets` -> `Get New...` -> `Download new Plasma Widgets` -> `search for "Wallpaper Switcher"`

Option 2:
Download the `package` folder and place everything inside it into `~/.local/share/plasma/plasmoids/com.github.aurus28/`
